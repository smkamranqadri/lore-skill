# lore 1.1.0: scheduled headless sync

Goal: interactive agents stop paying tokens for hub sync. A systemd user timer runs a gate; the gate
starts one headless agent only when a sync is needed.

Decisions (owner, 2026-10-19):
- Backend B: `codex exec` with `gpt-6-luna` at low effort follows `commands/sync.md` (Tartib MCP).
- Gate (free, no model): run when local files changed, or the last sync is older than a day, or never.
- Timer every 30 minutes, plus a catch-up after boot. Logs so the interval can be tuned later.
- The index no longer carries the "sync due" line.

Scope: `lore.py sync-run` (gate, lock, run, log), `sync-log` (summary), `sync-timer install|remove|check`;
`sync:` line in the Codex adapter; drop the index line; docs, SKILL.md, sync.md; version 1.1.0.

Out of scope: other hosts' `sync:` commands, a Tartib REST path, macOS launchd.

Acceptance: tests/run.sh green with new sync-run tests (skip, run, busy, failure, log, timer files);
each new guard mutation-checked; one real forced run through Luna recorded in the log.
